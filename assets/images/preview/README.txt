Optional festival banner preview artwork.

Use either:
  festival_banner_preview.png
  festival_banner_preview.jpg

Option A (hero behind search) — recommended export:
  Size: 1440 x 560 px (or 1200 x 480 px minimum)
  Aspect: about 2.6 : 1 (wide rectangle)
  Safe zone: keep faces/logos in the center-right; leave left/top clear for
  white title + search (or design the poster without text and use app title fields later).

Option B (card below categories):
  Size: 1100 x 400 px
  Aspect: about 2.75 : 1

Use PNG or JPG, sRGB. After adding or replacing a file, stop and restart the app
(full restart — hot reload does not pick up new assets).
Aim under ~400 KB JPG (or compress PNG) for fast load on mobile data.
